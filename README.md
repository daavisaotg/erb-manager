# ERB Manager

Sistema de gestao da European Referee Board (futsal no Roblox): arbitros, folha de pagamento, rankings, desempenho, sumulas e possivel escala.

Site: https://daavisaotg.github.io/erb-manager/

Pagina unica em HTML. Os dados ficam em um banco Postgres no Supabase: leitura publica, escrita apenas para o dono (login por link no e-mail).
